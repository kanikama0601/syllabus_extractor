# syllabus_extractor
シラバス抽出ソフト

[香川高専Webシラバス](https://syllabus.kosen-k.go.jp/Pages/PublicDepartments?school_id=39&lang=ja) から、
1年〜現在の学年までの授業のシラバスを学年ごとに選んで PDF 化します。

- 学年ごとに「その学年だった開講年度」の科目一覧を使います
  (例: 令和8年度に5年生 → 1年は令和4年度、2年は令和5年度 … 5年は令和8年度)
- 科目は学年ごとにチェックボックスで選びます
- サイトの「PDF出力」ボタン (ロボット認証付き) は使いません。シラバスページの内容を公式 PDF と同じレイアウトの表に組み直し、Chromium で PDF にします

## セットアップ

```sh
uv sync
uv run playwright install chromium
```

## 使い方

```sh
uv run syllabus-extractor
```

1. 学科を選択
2. 現在の学年を選択
3. 学年ごとに PDF 化する科目を選択 (Space: 切替 / a: 全選択・全解除 / i: 反転 / Enter: 決定)
4. 学年ごとにまとめた PDF も作るかを選択

出力先:

- 科目ごと: `output/<学科名>/<学年>年_<開講年度>/26開講情報工学科（2019年度以降入学者）5画像工学.pdf`
- 学年ごとにまとめた PDF: `output/<学科名>/22開講情報工学科（2019年度以降入学者）1年_シラバス.pdf`
  (その学年で選んだ科目が順に並び、科目名のしおり付き)

### オプション

| オプション | 説明 |
| --- | --- |
| `--department-id 37` | 学科を ID で指定 (一覧選択を省略) |
| `--grade 5` | 現在の学年を指定 |
| `--year 2026` | 現在の年度 (西暦)。既定は今日の日付から算出 (4月始まり) |
| `--all` | 科目選択を省略し全科目を PDF 化 |
| `--merge` / `--no-merge` | 学年ごとにまとめた PDF を作る / 作らない (省略時は確認) |
| `--output DIR` | 出力先フォルダ |

シラバスページの閲覧時に認証画面が出た場合は、ブラウザウィンドウが開きます。
手動で認証すると、その後の処理が続行されます。
